# Intake: keyword portfolio & target pages

The facts layer for the SEO workstream. Holds the keyword portfolio, the list of target pages, and current rankings/traffic snapshots that strategy and audits are built from.

## What goes here

- Keyword portfolio export (CSV) with volume, difficulty, and intent — stable filename, refreshed in place.
- Target-page inventory: the URLs SEO work is prioritizing.
- Ranking/traffic snapshots pulled from Search Console or Ahrefs at each refresh.

## Boundary

Every metric is pulled live (Ahrefs/Search Console) or quoted from a dated snapshot — never invented. Cross-workstream scheduling lives in the umbrella agenda, not here.
